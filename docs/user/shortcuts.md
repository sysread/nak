# Keyboard shortcuts

The keys that save you the most time. Shortcuts are the same across
platforms except where noted — the `Mod` key is `Cmd` on macOS and
`Ctrl` everywhere else.

## Composer

| Keys | What it does |
| ---- | ------------ |
| `Enter` | New line. Plain Enter never sends, so long drafts aren't cut off mid-thought. |
| `Mod`+`Enter` | Sends the message. `Shift`+`Enter` does the same. |
| `Mod`+`Enter` *while a reply is streaming* | Queues the message instead of sending it. It goes out on its own when the reply finishes. See [queueing a message](./chat.md#queueing-a-message-while-a-reply-is-streaming). |

The composer's placeholder tells you which of the last two you'll
get - it reads "sends" when idle and "queues" while a reply is
streaming.
